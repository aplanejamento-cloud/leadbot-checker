# LeadBot 24h

> **Seu cliente chama no WhatsApp fora do horário e o lead desaparece?**
> 
> O LeadBot qualifica leads automaticamente pelo WhatsApp e entrega oportunidades quentes na sua mão — enquanto o cliente está interessado.

## Para quem é

| Segmento | Dor |
|----------|-----|
| **Lojas de roupas** | Cliente pergunta "tem no M?" fora do horário → vai no concorrente |
| **Salões / Barbearias** | Agenda cheia, cliente não consegue marcar → desiste |
| **Imobiliárias** | Lead de imóvel chega às 22h → esfria antes do corretor responder |
| **Clínicas / Estéticas** | Paciente quer agendar, secretária ocupada → marca no concorrente |
| **Prestadores de serviço** | Orçamento que demora é orçamento perdido |

**Para NÃO é:** programadores procurando código gratuito, usuários n8n avançados, ou pessoas buscando reconstruir o produto.

## O que você recebe

- Template n8n: fluxo de qualificação QUENTE/MORNO/FRIO
- Guia passo a passo: configuração em 30 minutos
- Exemplos para: imobiliária, clínica, salão, loja, prestador
- Suporte inicial via Issues

## Resultado

| Antes | Depois |
|-------|--------|
| Cliente manda WhatsApp → silêncio | Cliente recebe resposta em segundos |
| Lead esfria em horas | Lead quente na sua mão |
| Você perdendo R$ 3.000–10.000/mês | Você respondendo enquanto dorme |

## Como funciona (simplificado)

```
Cliente → WhatsApp → LeadBot → Qualificação → Você recebe lead quente
  2s        24h        regras       QUENTE/MORNO/FRIO        feche a venda
```

O LeadBot usa **n8n** + regras (sem IA cara) para automatizar o primeiro atendimento. Você mantém controle total — o robô acelera o contato, não toma decisões de venda sozinho.
