Twilio WhatsApp Sandbox: Automatize Seu Atendimento sem Custo

Você sabe que o WhatsApp é essencial para o seu negócio, mas como testar automações sem gastar dinheiro? O Twilio WhatsApp Sandbox é a solução perfeita para você começar a testar automações gratuitamente antes de investir em uma solução completa.

Passo a Passo para Configurar o Twilio WhatsApp Sandbox

1. Crie uma Conta no Twilio

Primeiro, acesse o site do Twilio e crie uma conta. Você terá acesso a um saldo de teste para começar.

2. Acesse o Console do Twilio

Após criar sua conta, acesse o console do Twilio e navegue até a seção 'WhatsApp Sandbox'.

3. Configure o Sandbox

No WhatsApp Sandbox, você encontrará um número de telefone e um código de ativação. Envie uma mensagem para o número fornecido com o código de ativação para começar.

Exemplo: Envie 'join <código>' para o número fornecido.

4. Use o Código para Testes

Você pode usar o seguinte código para enviar uma mensagem de teste:

const accountSid = 'SEU_ACCOUNT_SID';
const authToken = 'SEU_AUTH_TOKEN';
const client = require('twilio')(accountSid, authToken);

client.messages.create({
    body: 'Olá, esta é uma mensagem de teste!',
    from: 'whatsapp:+14155238886',
    to: 'whatsapp:+SEU_NUMERO'
})
.then(message => console.log(message.sid))
.catch(err => console.error(err));
