💡 Como Qualificar Leads no WhatsApp com n8n + IA Grátis

Você recebe mensagens no WhatsApp de potenciais clientes, mas não tem tempo para analisar cada uma, descobrir o grau de interesse e encaminhá‑las para o time de vendas? Essa falta de filtragem gera perda de oportunidades e sobrecarga na sua equipe.

Passo a passo (código pronto para copiar)

  1. Crie o webhook no n8n – ele receberá as mensagens do WhatsApp. 
    // n8n webhook node (GET/POST)
{
  "name": "Webhook WhatsApp",
  "type": "n8n-nodes-base.webhook",
  "parameters": {
    "httpMethod": "POST",
    "path": "whatsapp-leads"
  }
}
  2. Integre o Twilio (ou outra API de WhatsApp) para encaminhar a mensagem ao webhook. 
    // Exemplo de request cURL
curl -X POST https://seusite.com/webhook/whatsapp-leads \
  -d '{"from":"+551199999999","body":"Quero orçamento"}' \
  -H "Content-Type: application/json"
  3. Adicione um node “HTTP Request” para chamar a IA gratuita (ex.: Ollama ou OpenAI free tier). 
    {
  "name": "IA Qualifica Lead",
  "type": "n8n-nodes-base.httpRequest",
  "parameters": {
    "url": "https://api.openai.com/v1/chat/completions",
    "method": "POST",
    "headerParametersJson": "{\"Authorization\":\"Bearer SUA_API_KEY\"}",
    "bodyParametersJson": "{\"model\":\"gpt-3.5-turbo\",\"messages\":[{\"role\":\"system\",\"content\":\"Classifique o lead como quente, morno ou frio. Responda apenas com a palavra.\"},{\"role\":\"user\",\"content\":\"{{$json[\\\"body\\\"]}}\"}]}",
    "jsonParameters": true,
    "options": {"responseFormat":"json"}
  }
}
  4. Parseie a resposta e envie a classificação de volta ao WhatsApp. 
    // Set node (extract classification)
{
  "name": "Definir Classificação",
  "type": "n8n-nodes-base.set",
  "parameters": {
    "values": [
      {
        "name": "classificacao",
        "value": "={{$json[\"choices\"][0][\"message\"][\"content\"].trim()}}"
      }
    ]
  }
}
  5. Use outro “HTTP Request” (Twilio) para responder ao cliente. 
    {
  "name": "Responder WhatsApp",
  "type": "n8n-nodes-base.httpRequest",
  "parameters": {
    "url": "https://api.twilio.com/2010-04-01/Accounts/ACXXXXX/Messages.json",
    "method": "POST",
    "authentication": "basicAuth",
    "basicAuthUser": "ACXXXXX",
    "basicAuthPassword": "SEU_AUTH_TOKEN",
    "bodyParametersJson": "{\"From\":\"whatsapp:+14155238886\",\"To\":\"{{ $json[\"from\"] }}\",\"Body\":\"Obrigado! Seu lead foi classificado como {{$node[\"Definir Classificação\"].json.classificacao}}.\"}"
  }
}
  6. Salve o lead em uma planilha Google (ou Airtable) para o time de vendas. 
    // Google Sheets node (simplificado)
{
  "name": "Salvar Lead",
  "type": "n8n-nodes-base.googleSheets",
  "parameters": {
    "sheetId": "SUA_SHEET_ID",
    "range": "Leads!A:D",
    "operation": "append",
    "valueInputOption": "RAW",
    "values": [
      ["{{$json[\"from\"]}}","{{$json[\"body\"]}}","{{$node[\"Definir Classificação\"].json.classificacao}}","{{ $now }}"]
    ]
  }
}

Copie cada bloco JSON acima direto no editor de fluxo do n8n → “Importar → JSON”. Conecte na ordem mostrada e ative o workflow.
