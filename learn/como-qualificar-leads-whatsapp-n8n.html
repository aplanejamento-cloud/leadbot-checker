Qualifique Leads no WhatsApp com n8n e IA Grátis

Você está perdendo tempo respondendo manualmente a cada lead que chega pelo WhatsApp? Muitas pequenas empresas enfrentam esse problema, gastando horas do dia apenas para qualificar leads que nem sempre se convertem em vendas. Com n8n e IA, você pode automatizar esse processo e focar no que realmente importa: fechar negócios.

Passo 1: Configure o n8n

Primeiro, você precisa ter o n8n instalado. Você pode usar a versão gratuita em n8n.io.

npm install n8n -g

Passo 2: Crie um novo workflow

No n8n, crie um novo workflow e adicione um nó de WhatsApp para receber as mensagens.

Passo 3: Adicione um nó de IA

Use um nó de HTTP Request para se conectar a uma API de IA gratuita, como a do Hugging Face.

{
  "nodes": [
    {
      "parameters": {
        "url": "https://api-inference.huggingface.co/models/facebook/blenderbot-400M-distill",
        "options": {
          "method": "POST",
          "headers": {
            "Authorization": "Bearer SEU_TOKEN_AQUI",
            "Content-Type": "application/json"
          },
          "body": {
            "inputs": {
              "text": "{{$node["WhatsApp"].json["messages"][0]["text"]}}"
            }
          }
        }
      },
      "name": "HuggingFace",
      "type": "n8n-nodes-base.httpRequest",
      "typeVersion": 1,
      "position": [
        500,
        300
      ]
    }
  ]
}

Passo 4: Configure a resposta automática

Adicione um nó de WhatsApp para enviar a resposta gerada pela IA de volta para o lead.
