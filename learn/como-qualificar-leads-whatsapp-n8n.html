🚀 Qualifique Leads no WhatsApp em 5 Minutos com n8n + IA Grátis

Você recebe dezenas de mensagens no WhatsApp todos os dias, mas acaba perdendo oportunidades porque não tem como filtrar quem realmente está pronto para comprar. A solução? Um fluxo automático (LeadBot) que usa n8n e IA gratuita para fazer a triagem, responder e encaminhar apenas os leads qualificados para a sua equipe.

Passo a passo (código pronto para copiar)

  1. Crie uma conta grátis em n8n.io e abra o editor.
  2. Adicione o nó Webhook (receber mensagens do WhatsApp via Twilio ou 360dialog).
  3. Conecte um nó HTTP Request à API gratuita da OpenAI (ou outro modelo de IA).
  4. Use o nó IF para decidir se o lead está qualificado (ex.: “sim” ou “não”).
  5. Envie a resposta ao usuário e, se qualificado, encaminhe ao seu CRM ou ao próprio WhatsApp.
