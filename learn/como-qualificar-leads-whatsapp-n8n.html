Como Qualificar Leads no WhatsApp com n8n + IA Grátis

Você está perdendo tempo qualificando leads manualmente no WhatsApp? Imagine se você pudesse automatizar esse processo e focar apenas nos leads mais promissores. Com n8n e IA, isso é possível e gratuito!

Passo a Passo para Qualificar Leads no WhatsApp

1. Configure seu ambiente n8n

Primeiro, você precisa ter o n8n instalado. Você pode usar a versão em nuvem ou instalar localmente.

Código mínimo para começar:

npm install n8n -g

2. Crie um novo workflow

Acesse o n8n e crie um novo workflow. Adicione um nó de WhatsApp para receber as mensagens.

Configuração básica:

{
  "nodes": [
    {
      "parameters": {
        "authentication": "credential",
        "operation": "receiveMessage"
      },
      "name": "WhatsApp",
      "type": "n8n-nodes-base.whatsapp",
      "typeVersion": 1,
      "position": [
        250,
        300
      ]
    }
  ]
}

3. Adicione um nó de IA para qualificar os leads

Use um nó de HTTP Request para enviar a mensagem para um serviço de IA gratuito, como o Hugging Face.

Exemplo de configuração:

{
  "nodes": [
    {
      "parameters": {
        "url": "https://api-inference.huggingface.co/models/roberta-base",
        "method": "POST",
        "headers": {
          "Authorization": "Bearer SEU_TOKEN"
        },
        "body": {
          "inputs": "{{$node["WhatsApp"].json["message"]}}"
        }
      },
      "name": "HuggingFace",
      "type": "n8n-nodes-base.httpRequest",
      "typeVersion": 1,
      "position": [
        450,
        300
      ]
    }
  ]
}

4. Classifique e responda automaticamente

Adicione um nó de Function para classificar os leads com base na resposta da IA e enviar uma resposta automática.

Exemplo de código:

const score = $input.all()[0].json[0][0].score;
if (score > 0.8) {
  return {
    message: "Olá! Vamos agendar uma reunião? Qual o melhor horário para você?"
  };
} else {
  return {
    message: "Obrigado pelo contato! Vamos manter comunicação."
  };
}
