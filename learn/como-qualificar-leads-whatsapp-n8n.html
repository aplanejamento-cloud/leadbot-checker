Qualifique Leads no WhatsApp em Segundos com n8n + IA Gratuita

Problema: Você recebe mensagens de clientes pelo WhatsApp, mas ainda gasta minutos — às vezes horas — filtrando quem realmente tem potencial de compra. O processo manual desperdiça tempo, gera erros e faz a sua equipe perder oportunidades.

Passo a passo (código mínimo copiável)

  1. Webhook do WhatsApp – Crie um Webhook no n8n que receba a mensagem: 
    <!-- n8n: Webhook Node -->
{
  "resource": "webhook",
  "operation": "listen",
  "httpMethod": "POST",
  "path": "whatsapp"
}
  2. Extraia o texto da mensagem – Use Set para isolar message.body. 
    <!-- n8n: Set Node -->
{
  "keepOnlySet": ["leadMessage"],
  "values": {
    "leadMessage": "={{$json[\"body\"][\"message\"][\"text\"][\"body\"]}}"
  }
}
  3. Classifique com IA gratuita – Chame a API da OpenAI (ou Gemini) sem custos básicos: 
    <!-- n8n: HTTP Request Node -->
{
  "url": "https://api.openai.com/v1/chat/completions",
  "method": "POST",
  "headers": {
    "Authorization": "Bearer SEU_TOKEN_OPENAI"
  },
  "body": {
    "model": "gpt-3.5-turbo",
    "messages": [
      {"role":"system","content":"Classifique a mensagem como lead quente, morno ou frio e retorne apenas a palavra."},
      {"role":"user","content":"={{$json.leadMessage}}"}
    ],
    "temperature": 0
  }
}
  4. Roteie a resposta – Use Switch para direcionar: 
    <!-- n8n: Switch Node -->
{
  "expression": "={{$json.choices[0].message.content.trim().toLowerCase()}}",
  "cases": [
    {"value":"quente","output":"LeadQuente"},
    {"value":"morno","output":"LeadMorno"},
    {"value":"frio","output":"LeadFrio"}
  ]
}
  5. Acione a ação desejada – Envie ao CRM, alerte a equipe ou responda ao cliente. 
    <!-- Exemplo: HTTP Request ao seu CRM -->
{
  "url": "https://api.seucrm.com/leads",
  "method": "POST",
  "json": true,
  "body": {
    "name": "={{$json.from}}",
    "message": "={{$json.leadMessage}}",
    "qualification": "={{$node[\"Switch\"].json}}"
  }
}

Perguntas frequentes

O que é n8n?

n8n é uma ferramenta de automação open‑source que permite criar fluxos (workflows) sem escrever código, usando blocos visuais.

Posso usar IA grátis?

Sim. As APIs de teste da OpenAI ou Gemini oferecem milhares de chamadas sem custo. Quando o limite acabar, basta mudar a chave.

Preciso de programação?

Não. O código acima pode ser copiado nos nós do n8n, mas a interface é drag‑and‑drop.
