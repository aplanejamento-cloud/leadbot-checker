Como qualificar leads no WhatsApp com n8n + IA grátis

Você recebe mensagens de potenciais clientes no WhatsApp, mas não tem tempo para analisar cada uma e descobrir se são oportunidades reais. O resultado? Leads “quentes” passam despercebidos e você perde vendas.

Neste tutorial você verá como automatizar a qualificação usando o n8n (workflow visual gratuito) e a IA gratuita da OpenAI. Em poucos minutos você terá um fluxo que classifica a intenção do lead e encaminha para o CRM ou para um agente humano.

Passo a passo

  1. Instale o n8n (Docker ou npm) e abra a interface web.
    docker run -d --name n8n -p 5678:5678 n8nio/n8n
  2. Crie um webhook para receber mensagens do WhatsApp. Use um provedor (Twilio, 360dialog, etc.) que envie POST ao endpoint /webhook/whatsapp do n8n.
  3. Adicione o nó “HTTP Request” para chamar a API da OpenAI.
    {
  "url": "https://api.openai.com/v1/chat/completions",
  "method": "POST",
  "headers": {
    "Authorization": "Bearer SEU_TOKEN_OPENAI",
    "Content-Type": "application/json"
  },
  "body": {
    "model": "gpt-3.5-turbo",
    "messages": [
      {"role":"system","content":"Classifique a mensagem como 'qualificado' ou 'não qualificado'."},
      {"role":"user","content":"{{ $json.body.message }}"}
    ],
    "temperature": 0
  }
}
  4. Parseie a resposta com um nó “Set” para extrair a classificação e crie duas ramificações:
    • Se qualificado, envie para o CRM (ex.: HubSpot) usando nó “HTTP Request”.
    • Se não qualificado, responda ao usuário agradecendo e pedindo mais informações.
  5. Teste o fluxo enviando uma mensagem real para o número do WhatsApp e verifique se o lead é encaminhado corretamente.
