Como Converter Leads de Madrugada no WhatsApp Automaticamente

Você recebe mensagens de clientes potenciais entre 00:00 e 04:00, mas sua equipe já está offline. Cada minuto perdido pode significar uma venda a menos. A solução? Automatizar a resposta e o encaminhamento desses leads para que a conversa continue assim que o atendimento for retomado.

Passo a passo (código mínimo copiável)

  1. Crie um webhook no n8n que receba a mensagem do WhatsApp (ex.: Twilio, 360dialog ou WhatsApp Business API).
    POST /webhook/whatsapp
{
  "from": "{{payload.from}}",
  "body": "{{payload.body}}",
  "timestamp": "{{payload.timestamp}}"
}
  2. Filtre mensagens enviadas fora do horário comercial (00:00‑04:00).
    // n8n Function node
const hour = new Date(item.timestamp * 1000).getHours();
if (hour >= 0 && hour < 4) {
  return [{ json: item }];
}
return []; // fora do intervalo, ignora
  3. Salve o lead em uma planilha (Google Sheets) ou CRM.
    // Google Sheets node – Append
{
  "sheetId": "YOUR_SHEET_ID",
  "range": "Leads!A:D",
  "values": [
    [
      "{{item.from}}",
      "{{item.body}}",
      "{{$now}}",
      "pendente"
    ]
  ]
}
  4. Envie uma resposta automática informando que o contato será atendido em breve.
    // WhatsApp send node
{
  "to": "{{item.from}}",
  "body": "Olá! Recebemos sua mensagem e entraremos em contato em até 1 hora. Enquanto isso, confira nosso FAQ: https://seusite.com/faq"
}
  5. Agende um lembrete interno (Slack, e‑mail ou notificação no próprio n8n) para que o time responda assim que o expediente iniciar.
    // Slack node
{
  "channel": "#leads-madrugada",
  "text": "Novo lead recebido às {{item.timestamp}}:\n• WhatsApp: {{item.from}}\n• Mensagem: {{item.body}}"
}
