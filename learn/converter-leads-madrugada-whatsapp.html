Como Converter Leads de Madrugada no WhatsApp Automaticamente

Problema real: Muitos negócios recebem mensagens de clientes entre 00h e 06h, mas quem está de plantão não tem tempo para responder, gerando perda de vendas e frustração.

Passo a passo (código mínimo copiável)

  1. Crie um Webhook Trigger no n8n que receba a notificação do WhatsApp (via Twilio, 360dialog ou WATI).
  2. Adicione um nó Set para mapear os campos nome, telefone e mensagem.
  3. Insira um nó HTTP Request que chame a API do LeadBot 24h: 
    POST https://api.leadbot24h.com/lead
Headers:
  Content-Type: application/json
Body:
{
  "name": "{{$json["nome"]}}",
  "phone": "{{$json["telefone"]}}",
  "message": "{{$json["mensagem"]}}",
  "schedule": "00:00-06:00"
}
  4. Use um nó Send WhatsApp Message (Twilio/360dialog) para confirmar o recebimento: 
    Olá {{ $json["nome"] }}, seu contato foi registrado e será atendido assim que possível!
  5. Salve e ative o workflow. Agora, toda mensagem recebida de madrugada entra automaticamente no LeadBot e fica pronta para follow‑up.
