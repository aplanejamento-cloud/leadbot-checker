Importar Workflow .json no n8n em 2 Cliques: Guia Rápido

Problema: Perder horas configurando workflows manualmente

Você já passou horas tentando configurar um workflow no n8n manualmente? Sabia que é possível importar um arquivo .json e ter tudo pronto em segundos? Este guia rápido vai te mostrar como fazer isso em apenas 2 cliques.

Passo a Passo para Importar Workflow .json no n8n

  1. Clique no botão de importar: No painel do n8n, clique no botão "Import from file" localizado no canto superior direito.
  2. Selecione o arquivo .json: Escolha o arquivo .json do workflow que você deseja importar. Pronto! Seu workflow será importado e estará pronto para uso.

Caso precise de um exemplo de arquivo .json para testar, você pode usar este código mínimo:

{
  "name": "Exemplo de Workflow",
  "nodes": [
    {
      "parameters": {},
      "name": "Start",
      "type": "n8n-nodes-base.start",
      "typeVersion": 1,
      "position": [
        250,
        300
      ]
    }
  ],
  "connections": {}
}
