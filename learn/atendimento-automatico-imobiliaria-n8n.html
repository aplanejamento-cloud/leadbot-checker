🚀 Atendimento Automático 24h para Imobiliárias com n8n + WhatsApp

Problema real: Corretoras recebem dezenas de mensagens por dia no WhatsApp, mas nem sempre conseguem responder rapidamente. Leads que ficam no vácuo acabam indo para a concorrência.

Passo a passo (código mínimo copiável)

  1. Crie a conta no n8n (cloud ou self‑hosted).

    Abra https://app.n8n.io, registre‑se e crie um novo workflow.

  2. Conecte o WhatsApp Cloud API.

    Instale o nó HTTP Request e configure:

    {
  "method": "POST",
  "url": "https://graph.facebook.com/v19.0/{{WHATSAPP_PHONE_ID}}/messages",
  "auth": {
    "type": "Bearer",
    "bearer": "{{WHATSAPP_ACCESS_TOKEN}}"
  },
  "json": true,
  "body": {
    "messaging_product": "whatsapp",
    "to": "{{$json["phone"]}}",
    "type": "text",
    "text": { "body": "Olá {{ $json["name"] }}, obrigado por entrar em contato! Em que posso ajudar?" }
  }
}

    Substitua {{WHATSAPP_PHONE_ID}} e {{WHATSAPP_ACCESS_TOKEN}} pelos valores da sua app Meta.

  3. Capture o lead via formulário (Google Forms, Typeform ou Webhook).

    Use o nó Webhook como gatilho:

    {
  "httpMethod": "POST",
  "path": "lead-imob"
}
  4. Mapeie os campos.

    Adicione um nó Set para garantir que o JSON tenha name e phone:

    {
  "name": "={{$json["nome"]}}",
  "phone": "={{$json["telefone"]}}"
}
  5. Encadeie os nós.

    Conecte Webhook → Set → HTTP Request. Salve e ative o workflow.

  6. Teste.

    Envie um POST para https://seusubdominio.n8n.cloud/webhook/lead-imob com JSON:

    {
  "nome": "João Silva",
  "telefone": "5511999999999"
}

    Você receberá a mensagem automática no WhatsApp do lead.
