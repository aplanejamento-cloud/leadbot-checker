Atendimento automático para imobiliárias com n8n e WhatsApp

Imobiliárias perdem dezenas de leads por dia porque não conseguem responder rapidamente no WhatsApp. O cliente envia uma mensagem, fica sem resposta e procura a concorrência. Automatizar esse primeiro contato garante que cada lead seja qualificado, agendado e nutrido sem esforço manual.

Passo a passo (código mínimo copiável)

  1. Crie a credencial do WhatsApp no n8n (Twilio, 360dialog, etc.) e anote o API_KEY.
  2. Instale o node n8n-nodes-whatsapp (ou use o nó nativo de HTTP Request).
  3. Copie e cole o fluxo JSON abaixo no editor de fluxo do n8n: 
    {
  "nodes": [
    {
      "parameters": {
        "triggerOn": "newMessage",
        "whatsappCredentials": "={{$json[\"credentialsId\"]}}"
      },
      "name": "WhatsApp Trigger",
      "type": "n8n-nodes-whatsapp.trigger",
      "typeVersion": 1,
      "position": [250, 300]
    },
    {
      "parameters": {
        "functionCode": "return [{ json: { nome: $json.body.match(/Nome:\\s*(.*)/i)[1] || \"Cliente\", telefone: $json.from } }];"
      },
      "name": "Extrair Dados",
      "type": "n8n-nodes-base.function",
      "typeVersion": 1,
      "position": [450, 300]
    },
    {
      "parameters": {
        "resource": "contact",
        "operation": "upsert",
        "email": "={{$json[\"nome\"].toLowerCase().replace(/\\s+/g,'')}}@leadbot.com",
        "firstName": "={{$json[\"nome\"]}}",
        "phoneNumber": "={{$json[\"telefone\"]}}"
      },
      "name": "CRM – Upsert Contato",
      "type": "n8n-nodes-base.pipedrive",
      "typeVersion": 1,
      "position": [650, 300]
    },
    {
      "parameters": {
        "text": "Oi {{ $json.nome }}, tudo bem? Sou da {{ $json.company || \"Imobiliária XYZ\" }}. Gostaria de agendar uma visita ao imóvel que você procura?"
      },
      "name": "Responder Cliente",
      "type": "n8n-nodes-whatsapp.sendMessage",
      "typeVersion": 1,
      "position": [850, 300]
    }
  ],
  "connections": {
    "WhatsApp Trigger": {
      "main": [
        [
          {
            "node": "Extrair Dados",
            "type": "main",
            "index": 0
          }
        ]
      ]
    },
    "Extrair Dados": {
      "main": [
        [
          {
            "node": "CRM – Upsert Contato",
            "type": "main",
            "index": 0
          },
          {
            "node": "Responder Cliente",
            "type": "main",
            "index": 0
          }
        ]
      ]
    }
  }
}

    Altere apenas o campo whatsappCredentials para a ID da credencial criada no passo 1.

  4. Teste o fluxo enviando “Nome: João, Telefone: +55 11 99999‑8888” para o número WhatsApp configurado. O bot deve responder e criar o contato no CRM.
  5. Ative o fluxo e deixe rodando 24 h.
