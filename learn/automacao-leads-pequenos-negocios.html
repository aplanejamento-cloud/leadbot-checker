Automação de Leads para Pequenos Negócios: O Que Funciona de Verdade

Você tem um pequeno negócio, investe tempo em posts nas redes sociais e ainda assim as conversas não se transformam em vendas? O problema mais comum é a falta de um fluxo estruturado para captar, qualificar e nutrir leads. Sem automação, você perde oportunidades, gasta horas respondendo manualmente e ainda não tem métricas para melhorar seu processo.

Como criar sua automação em 4 passos

  1. Crie um Webhook no n8n (recebe o lead do formulário): 
    {
  "nodes": [
    {
      "parameters": { "path": "lead-captura" },
      "name": "Webhook",
      "type": "n8n-nodes-base.webhook",
      "typeVersion": 1,
      "position": [250,300]
    }
  ],
  "connections": {}
}
  2. Adicione um nó “Google Sheets” para armazenar o lead: 
    {
  "nodes": [
    {
      "parameters": {
        "sheetId": "SUA_PLANILHA_ID",
        "range": "Leads!A1",
        "valueInputMode": "USER_ENTERED",
        "appendMode": true,
        "columns": [
          {"name":"Nome","value":"{{$json["name"]}}"},
          {"name":"Email","value":"{{$json["email"]}}"},
          {"name":"Data","value":"{{=$now}}"}
        ]
      },
      "name": "Google Sheets",
      "type": "n8n-nodes-base.googleSheets",
      "typeVersion": 1,
      "position": [500,300]
    }
  ],
  "connections": { "Webhook": { "main": [ [ { "node": "Google Sheets", "type": "main", "index": 0 } ] ] } }
}
  3. Envie um e‑mail de boas‑vindas com o nó “Send Email”: 
    {
  "nodes": [
    {
      "parameters": {
        "fromEmail": "contato@seunegocio.com",
        "toEmail": "{{$json["email"]}}",
        "subject": "Obrigado por se conectar!",
        "htmlContent": "Olá {{$json["name"]}},
    Obrigado por entrar em contato. Em breve retornaremos."
      },
      "name": "E‑mail de Boas‑vindas",
      "type": "n8n-nodes-base.emailSend",
      "typeVersion": 1,
      "position": [750,300]
    }
  ],
  "connections": { "Google Sheets": { "main": [ [ { "node": "E‑mail de Boas‑vindas", "type": "main", "index": 0 } ] ] } }
}
  4. Ative o workflow** e teste** enviando o formulário do seu site.
