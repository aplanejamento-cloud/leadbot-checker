Automação de Leads para Pequenos Negócios: O que Funciona

Você já investiu em anúncios, criou landing pages e ainda assim sente que os leads que chegam ao seu funil não são realmente qualificados? É comum perder tempo e dinheiro tentando transformar curiosos em clientes sem um processo bem estruturado.

Além disso, o gerenciamento manual de mensagens no WhatsApp, e-mails e planilhas pode ser um gargalo que impede sua equipe de escalar. Se você quer automatizar a triagem de leads e focar no fechamento, a solução certa está a apenas alguns cliques de distância.

Passo a Passo (Código mínimo copiável)

  1. Crie um webhook no n8n que receba a mensagem do WhatsApp: 
    POST https://seun8n.com/webhook/leadbot
{
  "name": "João",
  "phone": "+5511987654321",
  "message": "Quero saber mais"
}
  2. Conecte ao LeadBot 24h usando a API: 
    POST https://api.leadbot.io/v1/qualify
Headers: Authorization: Bearer SEU_TOKEN
Body: {
  "phone": "+5511987654321",
  "name": "João",
  "source": "WhatsApp"
}
  3. Retorne a resposta do LeadBot para enviar mensagem de qualificação: 
    {
  "status":"qualificado",
  "score": 85,
  "nextStep":"Enviar proposta"
}
  4. Envie a mensagem via WhatsApp API (exemplo com Twilio): 
    POST https://api.twilio.com/2010-04-01/Accounts/ACXXXXX/Messages.json
Body: {
  "From":"whatsapp:+14155238886",
  "To":"whatsapp:+5511987654321",
  "Body":"Olá João! Seu score é 85%. Gostaria de receber a proposta?"
}
