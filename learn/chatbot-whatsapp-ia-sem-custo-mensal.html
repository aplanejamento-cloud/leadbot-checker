Chatbot de WhatsApp com IA sem custo mensal: Guia passo a passo

Problema real: Pequenos negócios precisam responder rapidamente a clientes no WhatsApp, mas a maioria das soluções cobra assinaturas mensais caras. Este tutorial mostra como montar seu próprio bot usando ferramentas gratuitas, sem comprometer a qualidade.

Passo a passo

  1. Crie uma conta no Meta Cloud e habilite a API do WhatsApp Business. Siga o assistente para gerar o WhatsApp Business Account ID e a Phone Number ID.
  2. Obtenha um token de acesso. No painel da Meta, copie o Access Token (guarde em lugar seguro).
  3. Instale Node.js (versão 18+).
  4. Crie um novo projeto e instale dependências:
    5. mkdir meu-chatbot
cd meu-chatbot
npm init -y
npm install express axios body-parser
  5. Copie o código abaixo para index.js:
    6. const express = require('express');
const axios = require('axios');
const bodyParser = require('body-parser');

const app = express();
app.use(bodyParser.json());

const WHATSAPP_TOKEN = 'SEU_ACCESS_TOKEN';
const PHONE_ID = 'SEU_PHONE_NUMBER_ID';
const OPENAI_API_KEY = 'SUA_API_KEY_GRATUITA';

// Recebe mensagens do WhatsApp
app.post(`/webhook/${PHONE_ID}`, async (req, res) => {
    const msg = req.body.entry?.[0]?.changes?.[0]?.value?.messages?.[0];
    if (!msg) return res.sendStatus(200);

    const from = msg.from;
    const text = msg.text?.body || '';

    // Chama IA (ex.: OpenAI)
    const aiResponse = await axios.post(
        'https://api.openai.com/v1/chat/completions',
        {
            model: 'gpt-3.5-turbo',
            messages: [{role: 'user', content: text}]
        },
        {headers: {'Authorization': `Bearer ${OPENAI_API_KEY}`}}
    );

    const reply = aiResponse.data.choices[0].message.content.trim();

    // Envia resposta ao WhatsApp
    await axios.post(
        `https://graph.facebook.com/v16.0/${PHONE_ID}/messages`,
        {
            messaging_product: 'whatsapp',
            to: from,
            text: {body: reply}
        },
        {headers: {'Authorization': `Bearer ${WHATSAPP_TOKEN}`}}
    );

    res.sendStatus(200);
});

// Verificação do webhook (Meta)
app.get(`/webhook/${PHONE_ID}`, (req, res) => {
    const mode = req.query['hub.mode'];
    const token = req.query['hub.verify_token'];
    const challenge = req.query['hub.challenge'];
    if (mode && token && token === 'SEU_VERIFY_TOKEN') {
        res.status(200).send(challenge);
    } else {
        res.sendStatus(403);
    }
});

app.listen(3000, () => console.log('Bot rodando na porta 3000'));
  6. Configure variáveis: Substitua SEU_ACCESS_TOKEN, SEU_PHONE_NUMBER_ID, SUA_API_KEY_GRATUITA e SEU_VERIFY_TOKEN pelos valores obtidos nos passos anteriores.
  7. Hospede o código. Use um serviço free‑tier como Render ou Railway. Basta apontar o repositório e definir a porta 3000.
  8. Configure o webhook na Meta. No painel da API do WhatsApp, adicione a URL pública do seu app (ex.: https://seuprojeto.onrender.com/webhook/SEU_PHONE_NUMBER_ID) e o token de verificação.
  9. Teste! Envie uma mensagem para o número configurado e veja a IA responder automaticamente.
