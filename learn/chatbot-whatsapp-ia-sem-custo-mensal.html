Como criar chatbot de WhatsApp com IA sem custo mensal fixo

Empreendedores e pequenos negócios frequentemente perdem tempo (e dinheiro) tentando montar um bot de WhatsApp que responda automaticamente. A maioria das plataformas cobra mensalidades altas ou exige conhecimento avançado de programação e servidores. Nesta página você vai descobrir como montar o seu próprio chatbot usando ferramentas gratuitas e sem pagar nada por mês.

Passo a passo

  1. Crie uma conta no Dialogflow CX (gratuito) e configure um agente de IA.
    // Exemplo de intent simples no Dialogflow
intent: "Saudação"
training_phrases: ["Oi", "Olá", "Bom dia"]
responses: ["Olá! Como posso ajudar você hoje?"]
  2. Obtenha um número de WhatsApp via Twilio Sandbox (versão free). Anote o ACCOUNT_SID, AUTH_TOKEN e o WhatsApp Number.
  3. Hospede um webhook gratuito. Use o Railway (camada grátis) para rodar um pequeno script Node.js: 
    const express = require('express');
const bodyParser = require('body-parser');
const { SessionsClient } = require('@google-cloud/dialogflow-cx');

const app = express();
app.use(bodyParser.json());

const sessionClient = new SessionsClient();
const projectId = 'SEU_PROJECT_ID';
const location = 'global';
const agentId = 'SEU_AGENT_ID';

app.post('/webhook', async (req, res) => {
  const message = req.body.Body;
  const sessionPath = sessionClient.projectLocationAgentSessionPath(
    projectId, location, agentId, req.body.From
  );

  const request = {
    session: sessionPath,
    queryInput: {
      text: { text: message },
      languageCode: 'pt-BR',
    },
  };
  const [response] = await sessionClient.detectIntent(request);
  const reply = response.queryResult.responseMessages[0].text.text[0];

  // Envia resposta via Twilio
  const twilio = require('twilio')(process.env.TWILIO_SID, process.env.TWILIO_TOKEN);
  await twilio.messages.create({
    from: 'whatsapp:' + process.env.TWILIO_NUMBER,
    to: req.body.From,
    body: reply,
  });
  res.sendStatus(200);
});

app.listen(process.env.PORT || 3000);

    Copie o código acima, ajuste SEU_PROJECT_ID e SEU_AGENT_ID, e faça deploy no Railway.

  4. Configure o webhook no Twilio. No console do Twilio, em Sandbox > Settings > When a message comes in, coloque a URL do seu endpoint Railway (ex.: https://seu-app.railway.app/webhook).
  5. Teste! Envie "Oi" para o número do sandbox e veja a IA responder.
