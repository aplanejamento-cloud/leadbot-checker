Gemini grátis no n8n: configuração passo a passo

Problema real: Você tem um site ou um chatbot e quer respostas inteligentes sem pagar por APIs caras. O Google Gemini oferece um plano gratuito, mas muitos não sabem como integrá‑lo ao n8n para criar automações poderosas.

Passo a passo (código mínimo copiável)

  1. Crie credenciais Gemini no n8n 
    1️⃣ Abra Credenciais → Nova Credencial → escolha Gemini API
2️⃣ Cole sua API Key (obtida em https://ai.google.dev) 
3️⃣ Salve
  2. Monte o workflow básico 
    {
  "nodes": [
    {
      "parameters": {
        "prompt": "Escreva um resumo de 50 palavras sobre {{ $json[\"texto\"] }}."
      },
      "name": "Gemini Prompt",
      "type": "n8n-nodes-base.gemini",
      "typeVersion": 1,
      "position": [250,300],
      "credentials": {
        "geminiApi": "Gemini API"
      }
    }
  ],
  "connections": {}
}

    Arraste o nó Gemini Prompt, conecte a um Webhook ou Trigger e teste.

  3. Teste a execução

    Envie um POST para o webhook com JSON:
    {"texto":"benefícios da automação"}"

    O n8n retornará o resumo gerado pelo Gemini.

  4. Salve e ative

    Depois de validar, habilite o workflow e use-o em integrações (Zapier, Make, etc.).
