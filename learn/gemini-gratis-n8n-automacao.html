Gemini Grátis no n8n: Automatize Seu Negócio em Minutos!

Você está perdendo tempo com tarefas repetitivas no seu pequeno negócio? Automatizar processos pode parecer complicado, mas com o n8n e o Gemini, você pode começar a economizar tempo e dinheiro hoje mesmo. Neste guia, vamos mostrar como configurar o Gemini grátis no n8n de forma simples e direta.

Passo a Passo para Configurar o Gemini no n8n

Passo 1: Crie uma Conta no n8n

Se você ainda não tem uma conta no n8n, acesse o site oficial e crie uma conta grátis.

Passo 2: Instale o n8n

Você pode instalar o n8n localmente ou usar a versão em nuvem. Para instalar localmente, use o seguinte comando no terminal:

npm install n8n -g

Passo 3: Configure o Gemini

No painel do n8n, adicione um novo nó e procure por "Gemini". Configure o nó com suas credenciais. Você pode obter uma chave de API grátis no site do Gemini.

{ "nodes": [ { "parameters": { "apiKey": "SUA_CHAVE_DE_API_AQUI" }, "name": "Gemini", "type": "n8n-nodes-base.gemini", "typeVersion": 1, "position": [ 250, 300 ] } ] }

Passo 4: Crie Seu Primeiro Workflow

Adicione nós adicionais para criar um workflow completo. Por exemplo, você pode conectar o Gemini a um nó de e-mail para enviar mensagens automatizadas.
