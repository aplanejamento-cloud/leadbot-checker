Gemini grátis no n8n: configuração passo a passo

Você quer usar IA avançada nos seus workflows sem gastar nada? O modelo Gemini, da Google, oferece uma camada gratuita que pode ser conectada ao n8n em poucos minutos. Muitos usuários ainda se perdem ao criar credenciais ou montar o fluxo correto, gerando frustração e perda de tempo.

Neste guia vamos resolver esses pontos: criaremos a credencial, configuraremos o nó HTTP Request e testaremos a resposta. Tudo isso com código pronto para copiar e colar.

Passo a passo

  1. Obtenha a chave de API Gemini
    Acesse Google AI Studio, crie um projeto e copie a chave que aparece em API key.
  2. Crie a credencial no n8n
    # No n8n → Credenciais → Nova credencial → “API Key”
    Nome: Gemini
    Chave: sua-chave-aqui
  3. Monte o fluxo
    1. Arraste um nó HTTP Request.
    2. Selecione a credencial “Gemini”.
    3. Configure:
      • URL: https://generativelanguage.googleapis.com/v1/models/gemini-pro:generateContent
      • Method: POST
      • Body (JSON): { "contents":[ {"role":"user","parts":[{"text":"{{ $json.prompt }}"}]} ] }
  4. Teste
    Defina um nó “Set” antes do HTTP Request com a propriedade prompt = “Qual a capital da Austrália?”. Execute o workflow e veja a resposta no nó seguinte.
