Gemini Grátis no n8n: Automatize sem Custo e Aumente sua Produtividade

Você está perdendo tempo com tarefas repetitivas e quer automatizá-las, mas não tem orçamento para ferramentas caras? O Gemini grátis no n8n pode ser a solução perfeita para o seu pequeno negócio. Neste guia, vamos mostrar como configurar o Gemini no n8n passo a passo, sem custos.

Passo a Passo para Configurar o Gemini Grátis no n8n

Passo 1: Crie uma Conta no n8n

Primeiro, acesse o site do n8n e crie uma conta gratuita. Você pode usar o n8n na nuvem ou instalar localmente.

Passo 2: Obtenha sua Chave de API do Gemini

Acesse o Google AI Studio, faça login com sua conta Google e crie uma nova chave de API para o Gemini.

// Exemplo de chave de API (substitua pela sua)
const API_KEY = 'sua_chave_de_api_aqui';

Passo 3: Configure um Novo Workflow no n8n

No painel do n8n, clique em "New Workflow" e adicione um novo nó HTTP Request. Configure o nó com as seguintes informações:

{
  "nodes": [
    {
      "parameters": {
        "url": "https://generativelanguage.googleapis.com/v1beta/models/gemini-pro:generateContent",
        "method": "POST",
        "headers": {
          "Content-Type": "application/json"
        },
        "body": {
          "contents": [
            {
              "parts": [
                {
                  "text": "Conteúdo a ser enviado para o Gemini"
                }
              ]
            }
          ]
        },
        "authentication": "header",
        "headerAuth": {
          "name": "x-goog-api-key",
          "value": "sua_chave_de_api_aqui"
        }
      },
      "name": "HTTP Request",
      "type": "n8n-nodes-base.httpRequest",
      "typeVersion": 1,
      "position": [
        250,
        300
      ]
    }
  ]
}

Passo 4: Teste e Ative o Workflow

Clique em "Execute Workflow" para testar a configuração. Se tudo estiver correto, ative o workflow para que ele seja executado automaticamente.
